# Quick Reference: AI Tools by Use Case

A quick lookup guide to find the right AI tool for your specific needs.

## 🎯 Common Use Cases

### I want to...

#### Build a Chatbot or Conversational AI
- **LangChain** - Framework for LLM applications
- **LlamaIndex** - Data framework for RAG applications
- **OpenAI GPT-4** - Advanced language model
- **Anthropic Claude 3** - AI assistant with strong reasoning

#### Generate or Edit Images
- **Midjourney** - High-quality artistic images
- **DALL-E 3** - OpenAI's image generation
- **Stable Diffusion XL** - Open-source image generation
- **Adobe Firefly** - Professional creative tools

#### Process or Analyze Text
- **spaCy** - Industrial-strength NLP
- **Hugging Face Transformers** - Pre-trained models library
- **OpenAI GPT-4** - Text analysis and generation

#### Work with Audio or Speech
- **Whisper** - Speech recognition and transcription
- **ElevenLabs** - Voice generation and cloning
- **AudioCraft** - Music and audio generation

#### Detect Objects in Images/Video
- **YOLO v8** - Real-time object detection
- **SAM (Segment Anything)** - Image segmentation
- **Roboflow** - Computer vision platform

#### Generate Code
- **GitHub Copilot** - AI pair programmer
- **Cursor** - AI-first code editor
- **Codeium** - Free AI code completion

#### Create or Edit Videos
- **Runway Gen-2** - AI video generation
- **Pika Labs** - Video creation platform
- **Synthesia** - AI video with avatars

#### Train ML Models
- **PyTorch 2.0** - ML framework
- **TensorFlow** - End-to-end ML platform
- **Ray** - Distributed computing framework
- **Weights & Biases** - Experiment tracking

#### Label or Annotate Data
- **Label Studio** - Open-source data labeling
- **Roboflow** - Computer vision labeling
- **Scale AI** - Data platform for AI

#### Deploy ML Models
- **Hugging Face Inference Endpoints** - Managed deployment
- **BentoML** - Model serving framework
- **Modal** - Serverless ML platform
- **Triton Inference Server** - High-performance inference
